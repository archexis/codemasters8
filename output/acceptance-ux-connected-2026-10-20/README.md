## Простой основной сценарий

- Поиск ЖК, БИН и адреса доступен сразу на карте. Слои, риск и режимы карты остаются за прежней кнопкой. Escape закрывает панели, сохраняя введённый поиск. Проверяется обычный клик по zoom и маркеру, включая fallback без WebGL.
- Цитата, собственное обоснование конкретного факта и кнопки подтверждения/отклонения находятся в одной карточке. Черновик одного факта не подставляется в другой и сохраняется при неуспешном решении. Дата и дополнительное доказательство раскрываются по необходимости; для неизвестной даты и R3 они видны сразу.
- Пакетное решение свёрнуто, пока пользователь не выбирает факты. У него отдельное обоснование; проверки всего пакета и повторная доставка команд сохранены.
- Техническая история кандидата и сведения о запуске AI доступны по раскрытию. Успешный внешний анализ и локальный DEMO-parser явно различаются. Пользователю не нужно заполнять runId, хеш или версию инструкции.
- Сохранено ранее исправленное мобильное открытие оригинала: фокус и прокрутка к панели, возврат к исходной карточке при закрытии.

## Исправления инженерного качества

- Карточка кандидата вынесена в читаемый `FactCandidate.svelte`; основной компонент досье больше не содержит её плотную однострочную разметку.
- Исправлен воспроизведённый дефект подключённой подготовки: прежний ID `prep-` + 64 hex-символа превышал лимит Edge в 65 символов. Новый детерминированный ID сохраняет полный SHA-256 и укладывается в контракт. Это не ослабление проверки входа.
- Общий модуль строительных изображений поддерживает импорт JSON и вызов без Vite в настоящей Node/Playwright-приёмке.
- У серверного PDF удалён завершающий отступ, способный создавать пустую последнюю страницу. Проверка читабельности выполнена по всем страницам; серверная версия до и после пересмотра сравнивается побайтово.
- Поиск CSS-классов ограничен `src/`, чтобы генерируемые отчёты и диагностические исходники не участвовали в сборке стилей. Использован штатный механизм [Tailwind source()](https://tailwindcss.com/docs/detecting-classes-in-source-files#setting-your-base-path).
- Локаторы тестов привязаны к конкретному факту. Обновлены названия, ожидания и переходы live-набора; содержательные проверки баллов, изоляции, файлов, истории и повторных команд сохранены.

## Границы

Auth/БД/Storage/Edge проверяются на настоящем локальном Supabase; LLM — внешний настроенный провайдер. Материал, учётные записи и объекты синтетические, это проверка работающего соединения сервисов, а не подтверждение сведений о реальной стройке. В обычном live-наборе внешний inference отключён отдельной временной конфигурацией, чтобы негативные проверки не тратили вызовы провайдера.

Использованы временные аккаунты; их файлы удаляются перед удалением пользователей. Перед локальными миграциями сохранена резервная копия БД в игнорируемом `.temp/`. Существующие рабочие пространства не сбрасывались.

Этот отчёт не подтверждает развёртывание финальной рабочей копии на публичном сайте и не переносит результаты на другой набор байтов. Git-коммит и deployment не входят в результат этой локальной приёмки.

Промежуточные отчёты с отказами и прерванные прогоны сохранены. Они не заменяют итоговый результат. Среди исправленных причин: устаревшие локаторы после переноса полей, неверный ID подготовки, Node-импорт изображений, ожидание четырёхэтапного DEMO в пределах 5 секунд, запуск локального сервера под нагрузкой. Ни один тест не отключён; основной E2E-набор расширен проверкой независимых обоснований двух фактов.
