## 1. P2 — корректный по длине БИН блокирует создание и редактирование ЖК

**Шаги:**

1. Реестры → Добавить ЖК.
2. Заполнить название, адрес, застройщика и допустимые координаты (например, 49.95 / 82.6).
3. Ввести БИН `123456789012`.
4. Нажать «Сохранить объект».

**Фактически:** браузер фокусирует БИН и выводит «Введите данные в указанном формате». Объект не сохраняется. Та же ошибка воспроизведена в досье существующего «Янтарного мыса» → «Редактировать сведения ЖК».

**Ожидается:** поле пропускает строку из 12 цифр на проверке формата. Дополнительная проверка содержания БИН, если нужна, должна иметь отдельное понятное сообщение.

**Диагностика:** в реальном DOM значение `pattern` равно `[0-9]12`, `validity.valid = false` при `value = 123456789012`. В `src/components/ComplexForm.svelte:33` записано `pattern="[0-9]{12}"`: Svelte интерпретирует `{12}` как выражение и теряет фигурные скобки. Рекомендуемая правка — передавать строку выражением, например `pattern={'[0-9]{12}'}`.

**Влияние:** стандартный сценарий добавления/изменения объекта с заполненным 12-значным БИН заблокирован. Это проверка HTML-шаблона, а не вывод о действительности конкретного БИН.

**Доказательства:** [скриншот](bin-validation-bug.png), [снимок создания](bin-create-snapshot.yml), [снимок редактирования](bin-edit-snapshot.yml), [значения HTML-валидации](bin-validation-observed.json).

## 2. P2 — легенда X-Ray блокирует «Открыть досье» на мобильной карте

**Шаги:**

1. Открыть карту при viewport 390×844.
2. Выбрать объект «Кедровый горизонт» через маркер или список.
3. В «Слои и фильтры» включить X-Ray «Правовой».
4. Закрыть панель фильтров.
5. Нажать «Открыть досье» в карточке предпросмотра.

**Фактически:** многострочная легенда перекрывает нижние кнопки карточки. Обычный click не проходит: Playwright повторяет попытку 5 секунд и сообщает, что `.map-legend.map-legend-float` перехватывает pointer events. Повторено после закрытия уведомления о сохранении и после закрытия фильтров. Независимо повторено на обычной подложке «Карта» в режиме 2D; спутник и 3D для ошибки не требуются.

**Ожидается:** легенда и действия карточки не перекрываются, кнопка открывает досье с первого нажатия.

**Контроль:** выключение X-Ray и переход в 2D позволили нажать эту же кнопку и открыть `#/complexes/SQ-002`. Подтверждено, что сам обработчик перехода работает.

**Область исправления:** позиционирование `.map-legend-float` в `src/app.css:280`, мобильные правила в `src/app.css:328` и более позднее переопределение `.map-preview` в `src/app.css:373`. У легенды `z-index: 4`, у карточки — 3; её высота меняется при переносе текста. Нужен достаточный отступ для фактической высоты легенды либо размещение её вне области действий.

**Доказательства:** [2D, чистый экран без уведомлений и фильтров](mobile-map-legal-2d.png), [лог неудачного click](mobile-map-click-failure.log), [снимок UI](mobile-map-legal-snapshot.yml). Дополнительные скриншоты: [с открытыми фильтрами](map-mobile.png), [без фильтров](mobile-map-blocked-clean.png).

## 3. P3 — исходный комментарий отображается на странице резервной копии

**Шаги:** Демо-аналитик → Резервная копия (`#/backup`).

**Фактически:** под заголовком показан полный служебный комментарий, начинающийся с `/** * S2.5 (C3). Backup/restore UI`, включая имена файлов, IndexedDB, RPC и внутренние обозначения C3/C6.

**Ожидается:** страница показывает пользовательское описание резервного копирования.

**Причина:** `src/components/BackupPanel.svelte:1` содержит JavaScript-комментарий вне `<script>`. В шаблоне Svelte он становится видимым текстом. Его нужно перенести в script либо оформить HTML-комментарием.

**Доказательства:** [скриншот](backup-source-comment.png), [снимок UI](backup-snapshot.yml).
