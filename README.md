# SAQ QURYLYS — сақ · мониторинг рисков долевого строительства

Демонстрационный MVP для хакатона **Codemasters 8.0** (кейс SAQ QURYLYS).
Аналитическая система для специалиста МИО / регионального аналитика:
обзор ЖК → карточка объекта → объявления → объяснимый риск → решение человека → сигнал → печать/PDF.

> **DEMO.** Все ЖК, компании, БИНы, адреса, документы и объявления вымышлены.
> Система подсвечивает признаки и помогает принять решение, но **не устанавливает
> факт правонарушения** и ничего не отправляет в госорганы автоматически.

## Быстрый запуск

Никакой сборки и зависимостей. Нужен только Python 3 или Node.

```bash
cd saq-qurylys
python3 -m http.server 8000
# открыть http://localhost:8000
```

Альтернатива: `npx serve .` или любое статическое хостинг-окружение.

## Тесты

```bash
node tests/test-scoring.cjs
node tests/test-parser.cjs
```

Проверяют: веса R1–R6, границы зон (красная только при R1+R2 одновременно),
«неизвестно ≠ R1», cap 100, точные сценарии A (35/yellow), B (70/red),
C (10/green) и целостность seed (≥8 ЖК, ≥12 объявлений, связи, DEMO-метки).

## Архитектура

- `index.html` — каркас, навигация (3 вкладки: Главная, Объекты, Проверка), модалки.
- `css/styles.css` — яркая дизайн-система: титульный hero с анимацией, бегущая строка,
  анимированные счётчики, пульс-метки карты, переходы видов.
- `js/data.js` — seed: 8 демо-ЖК (Өскемен), 13 объявлений, 11 ссылок на реестры РК
  (проверены 15.10.2026: 9 открываются, 2 молчат — помечено честно).
- `js/scoring.js` — детерминированный движок R1–R6, ноль зависимостей.
  Общий для браузера и тестов (`module.exports` + `window.SQ_Scoring`).
- `js/parser.js` — настоящий локальный парсер объявлений (ноль зависимостей):
  телефоны, суммы, готовность в %, даты, сроки, юридические маркеры, контакты —
  всё с дословными цитатами и уверенностью. Покрыт тестами (`tests/test-parser.cjs`).
- `js/ai.js` — адаптер извлечения гипотез. При настроенном ключе —
  реальный вызов OpenAI-совместимого endpoint; иначе **меченая
  DEMO-эвристика** (никогда не выдаётся за ИИ).
- `js/app.js` — интерфейс, workflow, localStorage-состояние.
- Карта: Leaflet + OpenStreetMap; метки только при наличии координат.

Правила скоринга: R1 +35 (только проверенное отсутствие основания),
R2 +25 (прямое предложение оплаты), R3 +10, R4 +15, R5 +10, R6 +5.
Балл = min(100, сумма подтверждённых). Зоны: 0–24 зелёная, 25–59 жёлтая,
60+ красная только при R1+R2 одновременно, иначе жёлтая.

## Путь демонстрации (2–3 минуты)

1. Главная: hero, счётчики, шаги, приоритет, реестры.
2. Объекты: фильтры зон, поиск, карта с пульс-метками, карточка SQ-002 (кейс B).
3. Проверка: пресет A/B/C → разбор парсера (сущности с цитатами) → гипотеза →
   Подтвердить → балл пересчитан, объявление в карточке ЖК.
4. Сигнальная карточка → Подтвердить → Печать/PDF (печатается только карточка).

## AI: как включить реальную модель

Кнопка «Настроить AI» в шапке → endpoint + model + key.
Ключ хранится только в localStorage браузера, в git не попадает.
Без ключа интерфейс честно показывает бейдж «DEMO — не настоящий ИИ».

## Ограничения

- Нет живой интеграции с госреестрами, парсинга, Telegram, OCR.
  Раздел «Реестры РК» — курированный список внешних ссылок для ручной сверки.
- Состояние — localStorage; кнопка «Сбросить демо» возвращает исходный seed.
- Карта требует интернета (CDN Leaflet/OSM); без него список работает полностью.
