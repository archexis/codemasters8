# SAQ QURYLYS — сақ · мониторинг рисков долевого строительства

Демонстрационный MVP для хакатона **Codemasters 8.0** (кейс SAQ QURYLYS).
Аналитическая система для специалиста МИО / регионального аналитика:
обзор ЖК → карточка объекта → объявления → объяснимый риск → решение человека → сигнал → печать/PDF.

> **DEMO.** Все ЖК, компании, БИНы, адреса, документы и объявления вымышлены.
> Система подсвечивает признаки и помогает принять решение, но **не устанавливает
> факт правонарушения** и ничего не отправляет в госорганы автоматически.

## Быстрый запуск

Никакой сборки и зависимостей. Нужен только Python 3 или Node.

```bash
cd saq-qurylys
python3 -m http.server 8000
# открыть http://localhost:8000
```

Альтернатива: `npx serve .` или любое статическое хостинг-окружение.

## Тесты

```bash
node tests/test-scoring.cjs
node tests/test-parser.cjs
node tests/test-sources.cjs
python3 tools/verify_ashyq.py
```

Проверяют: веса R1–R6, границы зон (красная только при R1+R2 одновременно,
включая минимум 60 = R1+R2 и 60 без R2 → жёлтая), R1/R2 поодиночке — жёлтые,
гипотеза R1 без подтверждения не даёт баллов, «неизвестно ≠ R1», cap 100,
точные сценарии A (35/yellow), B (70/red), C (10/green) и целостность seed
(≥8 ЖК, ≥12 объявлений, связи, DEMO-метки).
Парсер (57 проверок): RU+KZ платёжные маркеры (первоначалка, залог,
кепіл≠кепілдік, алғашқы/бастапқы жарна, ақы төлеу, перевод на карту),
отрицания в пределах предложения (без предоплаты/задатка/залога,
шарт бойынша, 0 тг), «не через эскроу» — отягчает, дословные цитаты+спаны.
`test-sources.cjs` (31 проверка): нормализация источника
(Krisha.kz, OLX, Instagram, TikTok, Telegram, WhatsApp, сайт застройщика —
по ссылке и подсказкам), каспи-перевод и номер карты как платёжный сигнал,
«пишите в личку/директ/вацап» — канальный маркер, а не R2, CSV-импорт
(; , таб, кавычки, RU/EN-заголовки), связи по телефону/аккаунту/ссылке,
дедуп с нормализацией телефонов.
`verify_ashyq.py` сверяет 8 строк public-snapshot с живым CSV Ashyq Data
(4005 строк, sdu_load_date 2026-06-15; 8 из 86 записей по Өскемену).

## Архитектура

- `index.html` — каркас, навигация (5 разделов: Главная, Объекты,
  Публикации, Проверка, Реестры) + меню «Сеанс» (вход, сброс). На мобильных —
  раскрывающееся меню.
- `css/styles.css` — яркая дизайн-система: титульный hero, анимированная SVG-сцена
  «от объявления к решению» (первый визит, пропуск, уважение к reduced-motion),
  анимированные счётчики, пульс-метки карты, переходы видов.
- `js/data.js` — seed: 8 демо-ЖК (Өскемен), 13 объявлений, 11 ссылок на реестры РК
  (проверены 15.10.2026: 9 открываются, 2 молчат — помечено честно).
- `js/scoring.js` — детерминированный движок R1–R6, ноль зависимостей.
  Общий для браузера и тестов (`module.exports` + `window.SQ_Scoring`).
- `js/parser.js` — настоящий локальный парсер объявлений (ноль зависимостей):
  телефоны, суммы, готовность в %, даты, сроки, юридические маркеры, контакты —
  всё с дословными цитатами и уверенностью. Покрыт тестами (`tests/test-parser.cjs`).
  v3: нормализация источника (веб/соцсети/мессенджеры), каспи-сигналы,
  канальные маркеры, CSV-импорт, связи и дедуп (`tests/test-sources.cjs`).
  Живого скрейпинга нет и не заявлено: тексты вставляет человек, ссылка
  и время снятия хранятся как доказательство.
- `js/ai.js` — разбор объявлений на гипотезы. Встроенный помощник работает
  сразу, без ключей и настройки. Своя внешняя модель — только по желанию:
  блок «Хочу свою модель — необязательно» в «Проверке» принимает
  OpenAI-совместимый адрес и ключ (только localStorage браузера).
- `js/app.js` — интерфейс, workflow, localStorage-состояние.
  «Проверка» идёт шагами 1·2·3 с вкладками (текст / сеть и соцсети / скриншот),
  быстрым выбором площадки, автоопределением по ссылке и CSV-предпросмотром
  с пометками «просьба денег» и «похоже на дубль». Лента показывает связи
  по телефону/аккаунту. Карточка ЖК — раздел «Площадка»: кадры с дрона
  и осмотров с датой, фиксация подтверждённой готовности, гипотеза R5
  при разрыве ≥20 п.п. (решение — за человеком).
- Карта: Leaflet + OpenStreetMap с переключателем на открытые снимки
  Esri World Imagery (без ключа); метки только при наличии координат.
  Дату спутниковой съёмки провайдер не сообщает — для выводов используйте
  датированные кадры из «Площадки».
- Главная: hero со сводкой, виджеты с долями, донат распределения зон,
  мгновенная проверка фразы («Попробуйте прямо сейчас») и лента
  «Последние изменения» (журнал решений + события + подтверждения
  факторов — всё из реальных данных состояния).

Правила скоринга: R1 +35 (только проверенное отсутствие основания),
R2 +25 (прямое предложение оплаты), R3 +10, R4 +15, R5 +10, R6 +5.
Балл = min(100, сумма подтверждённых). Зоны: 0–24 зелёная, 25–59 жёлтая,
60+ красная только при R1+R2 одновременно, иначе жёлтая.

## Путь демонстрации (2–3 минуты)

1. Главная: hero со сводкой, схема «от объявления к решению», проблема,
   таблица правил R1–R6, зоны, живые кейсы A·B·C, реестры, FAQ.
2. Объекты: фильтры зон, поиск, карта с пульс-метками, карточка SQ-002 (кейс B).
3. Проверка: пресет A/B/C → разбор парсера (сущности с цитатами) → гипотеза →
   Подтвердить → балл пересчитан, объявление в карточке ЖК.
4. Сигнальная карточка → Подтвердить → Печать/PDF (печатается только карточка).

## AI: ничего настраивать не нужно

Встроенный помощник работает сразу. Своя внешняя модель — только по желанию:
блок «Хочу свою модель — необязательно» под результатом «Проверки».
Ключ хранится только в localStorage браузера, в git не попадает.

## Вход (тестовый доступ)

Кнопка «Войти» в шапке: имени аналитика достаточно (минимум 2 символа),
пароля нет и не может быть — сервера авторизации не существует.
Имя подписывает решения в журнале и хранится только в localStorage;
кнопка «Выйти» стирает сессию. Это честно подписано в диалоге входа.

Маршруты — прямые ссылки: `#/overview`, `#/detail/SQ-002`, `#/signal/SQ-002`,
`#/analyze`, `#/registries`. Кнопки браузера
«назад/вперёд» работают.

## Ограничения

- Нет живой интеграции с госреестрами, скрейпинга, Telegram, OCR.
  Раздел «Реестры РК» — курированный список внешних ссылок для ручной сверки.
  Скриншоты и файлы площадки видны только в текущем сеансе (сохраняются
  дата, подпись, оценка); живого забора страниц нет — тексты вставляет человек.
- Состояние — localStorage; кнопка «Сбросить» в меню «Сеанс» возвращает исходный seed.
- Карта и спутник требуют интернета (CDN Leaflet/OSM/Esri); без него список работает полностью.
