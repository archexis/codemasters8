# Этажность зданий Өскемена

Карта использует локальную копию публичного государственного слоя
[«здания» КПСиСУ ГП РК](https://gis.kgp.kz/arcgis/rest/services/KPSSU/Gray_basemap/FeatureServer/1).
Государственные страницы [ссылаются на этот GIS-портал](https://www.gov.kz/memleket/entities/pravstat/press/news/details/444039?lang=ru).
Импорт выполняет только запросы чтения; редактирование исходного сервиса не используется.

## Что фактически покрыто

Выгрузка 21 октября 2026 года содержит все **110 669 полигональных записей**,
которые сервис возвращает по `location = 'Усть-Каменогорск'`.
У **110 592** записей этажность положительная, у **77** — `floor = 0`.
Отклонённых геометрий нет. Это количество записей/контуров, а не доказанное
количество уникальных реальных зданий. Городские гаражи и хозяйственные
постройки также входят в набор. Контуры охватывают диапазон примерно
82.427–82.799° в.д., 49.813–50.065° с.ш.; это границы найденных геометрий,
не административная граница города.

Дата съёмки и дата актуальности атрибутов источником не опубликованы.
Нельзя обещать полноту относительно существующего города или актуальность
каждого дома. В частности, новые здания могут отсутствовать. Более 60% записей
не имеют полного адреса, поэтому используются собственные контуры источника,
а не неточное сопоставление с OSM по строкам адресов.

## Высота и основание

- `floors` — этажность из официального поля `floor`, без изменения.
- `height` — **расчёт для отображения**, по умолчанию `floors × 3.2 м`.
  Это настраиваемое допущение, не измеренная высота, не норматив и не точный
  размер конкретного дома. Не учитывает реальные высоты этажей, кровлю и цоколь.
- `heightMethod = floors-estimate`; измеренных высот в наборе **0**.
- На карте применяется визуальное увеличение высоты ×2,5 (`cityHeightScale` в
  `RiskMap.svelte`). Оно не меняет этажность и высоты в исходных тайлах.
- `sourceHeightRaw` сохраняет исходное `h`. В этой выгрузке оно равно
  `floor × 4` при известной этажности и 4 при нулевой. Описание поля не содержит
  единиц/методики; использовать его как измеренную высоту нельзя.
- У неизвестной этажности `height = 0`: показывается плоский контур.
- Основание всех официальных объёмов равно 0. Рельеф отключён. Исходные
  `render_min_height` OpenFreeMap не переносятся на государственные контуры.

В пределах выгрузки новый слой **заменяет** старый серый слой OpenFreeMap,
чтобы не накладывать две разные геометрии. Цветные условные объекты ЖК — отдельный
слой; их 36-метровые условные коробки эта выгрузка не подтверждает.
Если официальный манифест не загружается, карта показывает явно обозначенный
резервный слой OpenFreeMap. В нём учитывается `hide_3d` и проверяется основание.

## Повторяемая выгрузка

Из корня проекта, Python 3.10+ (только стандартная библиотека) и Node.js:

```powershell
npm run buildings:fetch -- --refresh
npm run buildings:tiles
```

Без `--refresh` первый этап возобновляет скачивание из проверенного кэша.
Для обновления этажности существующих записей необходим `--refresh`.
Сырые страницы и GeoJSON находятся в игнорируемом `output/`, не включаются
в клиентский бандл. Метаданные содержат время самой старой страницы кэша,
время сборки выгрузки, исходную схему, счётчики и SHA-256 GeoJSON.

Высоту этажа можно задать явно, сохраняя маркировку расчётной высоты:

```powershell
npm run buildings:fetch -- --meters-per-floor 3.0
npm run buildings:tiles
```

Парсер получает количество записей, загружает упорядоченные страницы,
проверяет длину каждой страницы, уникальность и порядок ID, диапазон координат,
замкнутость колец и повторно запрашивает количество после загрузки.
Обрезанный ответ, дубли или изменение количества прекращают публикацию.
Это проверка целостности выгрузки, не транзакционный снимок базы:
источник не предоставляет версии и может менять атрибуты во время скачивания.

В `public/city-buildings/` хранятся версионированные MVT/PBF-тайлы z12–15
и манифест. На более близких масштабах MapLibre увеличивает z15.
Браузер запрашивает видимые тайлы; весь GeoJSON не скачивается.
Новый манифест публикуется только после завершения всех тайлов.
Старые версии можно удалить вручную после обновления всех развёрнутых клиентов.

Проверки:

```powershell
python -m unittest discover -s tools/tests -p test_building_registry.py -v
npx vitest run tests/unit/city-buildings.test.ts tests/unit/map-model.test.ts
npm run check
npm run build
```

## Другие проверенные источники

- [Геопортал ВКО](https://vkomap.kz/Index/Help), слой
  `https://vkomap.kz/Proxy/UK/UK/MapServer/0`: есть `FLOOR`, `STREET_1`,
  `NUMBER_1` и полигоны, но массовый счётчик и получение ID через публичный
  прокси не сработали. Неполный альтернативный набор не смешивается автоматически.
- Публичный WFS ЕГКН и data.egov.kz: общегородской слой существующих зданий
  Өскемена с доступными контурами и этажностью не подтверждён.
- OSM, OpenFreeMap и 2GIS не обозначаются государственными данными.

Публичная доступность API сама по себе не определяет лицензию переиспользования;
условия правообладателя сохраняются. Атрибуция источника показана на карте.
