# 01 — Map, X-Ray City & 2.5D

**Роль:** обнаружение и географическая ориентация, НЕ подтверждение фактов и НЕ юридическое заключение. Главный визуальный дифференциатор; обязательно работает в текущей вкладке «Карта».

## Компоновка

```text
Карта [поиск ЖК, БИН, адреса] [фильтр базовой зоны риска]
[Карта | Спутник]   [2D | 2.5D]   [X-Ray: выкл | Правовой | Стройка | Реклама]
───────────────────────────────────────────────────────────────────────────
КАРТА (занимает весь экран; 3D-экструзии при 2.5D)
   [выбранный ЖК] → floating-карточка в 2–3 строки + ключевой факт
                     [Открыть досье]  [Показать связи]
Низ: контекстная легенда, источник/актуальность, масштаб
```

**Не рисовать одновременно три слоя по умолчанию.** Пользователь выбирает ровно одну тему X-Ray; редкое наложение вынести в «Дополнительно». Общий риск/зона — отдельный фильтр/нейтральный бейдж, а не четвёртая тема X-Ray.

## Три понятных X-Ray-темы

1. **Правовой:** применимое основание (`гарантия КЖК`, `разрешение МИО` с типом, `требует проверки`, `подтверждённое отсутствие`), дата/источник. Дополнительный кадастровый подслой — только здесь и только при проверенных геоданных.
2. **Стройка:** плановая/подтверждённая готовность с периодом, отставание, последняя проверка, ссылка в «Хронологию». Прогноз/фото не выдавать за измеренную готовность.
3. **Реклама:** связанные публикации, наличие предложения о деньгах и статус проверки, ссылка к фрагменту публикации.

Легенда изменяется вместе с X-Ray-темой. Не использовать один и тот же красный цвет для статуса `unknown` и подтверждённого тревожного факта. Цвет обязателен в паре с текстом/значком.

## 2.5D — реалистичная геометрия

- Экструзия зданий и наклонная камера, кликабельный полигон/маркер. Не путать 2.5D-карту и отдельную 3D-модель сооружения на странице ЖК.
- Контур неизвестен → маркер без выдуманной формы; высота неизвестна → плоский контур либо явно `DEMO`-экструзия в демонстрационной среде.
- Сопоставление геометрии к `complexId`/`phaseId` документируется; не смешивать блоки разных очередей.
- Если текущая карта построена на Leaflet, нужен отдельный технический spike на рендерер экструзий и план миграции/adaptation. Не запускать два WebGL-картографических движка одновременно.

## Floating preview

Поля: ЖК/очередь, адрес, застройщик/БИН если есть, балл+зона, один основной проверенный признак, известность/актуальность данных, публикаций `n`.

CTA `Открыть досье` → `/complexes/:id?phase=...`; вторичное `Показать связи` → **только геопривязанные** соседние ЖК по проверенным отношениям. Роль компании без координат показывать списком, а не выдуманной точкой на карте.

## Состояния

`loading`, `ready`, `no_geometry`, `partial_data`, `no_live_registry`, `webgl_unavailable`, `demo`. В `webgl_unavailable` карта остаётся функциональной в 2D. При неработающем API источников карта не исчезает.

## Данные и события

Читать упрощённую проекцию `MapSummary` по viewport; детали получать при выборе (`ComplexPreview`), полные доказательства — только в досье. События `openDossier(complexId, phaseId)`, `showRelatedPlaces(complexId, max=...)`, `focusEvidence(id)`; карта сама не меняет проверки.

## DoD

- Настоящее переключение 2D/2.5D и одного X-Ray; выбор здания/маркера работает, floating preview открывает правильную очередь.
- Режимы опираются на фактические seed/импортированные/проверенные данные; неизвестность видима.
- Без WebGL/геометрии работает fallback; состояние камеры, фильтров и выбора сохраняется.
- Профиль производительности и lifecycle строго по `08_ENGINEERING_PERFORMANCE.md`.
