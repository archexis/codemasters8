# 05 — Risk Web (Relations)

**Роль:** граф объяснимых связей, а не самостоятельный скоринг. Основной UI: **вкладка «Связи»** в досье. Второй, лёгкий UI: «Показать связи» в floating-карточке на карте.

## Вкладка «Связи»

```text
[Граф | Список]   [Тип связи ▾]  [1 шаг | 2 шага]    [Развернуть]
─────────────────────────────────────────────────────────────────
Интерактивный граф             | Контекст выбранной связи
ЖК/очередь — центральный узел   | стороны и роли
организации, ЖК, реклама        | точный тип отношения
документы                       | подтверждение/источник
                                | [К оригиналу] [+ В материалы дела]
```

При разворачивании графа визуальная 1/3 скрывается, при возвращении — восстанавливается. `Граф / Список` — равноправные представления данных: большой граф без списка не годится для продуктивной работы.

## Узлы и рёбра

Узлы: `complex`, `phase`, `legal_entity` (по БИН), `advertising_account`, `publication`, `document`, опционально `land_parcel`. Рёбра: `developer_of`, `authorized_company_of`, `contractor_of`, `advertises`, `covered_by`, `mentions`, `same_ad_account`, `located_on`.

Каждое ребро хранит `from/to`, `relationType`, `sourceEvidenceIds`, `observedAt?`, `capturedAt`, `verificationStatus`, `matchMethod`. По одному названию совпадение — только кандидат; БИН — сильный идентификатор компании, но роль/отношение всё равно подтверждать документом. Общий рекламный аккаунт **не означает общего владельца**.

## Поведение в Investigation Mode

Клик узла/ребра → правый компактный inspector с источником. `Добавить в дело` сохраняет документальный контекст. Связь не даёт R1–R6 автоматически; если есть публикация с платным бронированием, её признак подтверждается в «Проверке» по оригиналу, а не из линии графа.

## Географическая проекция на главной карте

«Показать связи» показывает только связи между геолокализованными ЖК (максимум один шаг по умолчанию), с легендой типа отношения. Организации без надёжных координат выводить списком; не изображать физические маршруты денег и не рисовать ребро до «центра города» для юридического лица.

## Производительность

По умолчанию bounded neighbourhood (например, до 80 узлов/160 рёбер — целевой UX-лимит, не обрезание данных в БД). При превышении показывать `Скрыто ещё N связей` + раскрытие/поиск. Layout в worker или заранее вычисленный, анимация/physics выключаются при неактивной вкладке, вкладка грузится лениво. Export/print графа — необязательное дополнение, не условие MVP.

## DoD

Граф и список одного набора связей; центр строго выбранная очередь; по каждому ребру есть источник и статус; связи из рекламы/документов связаны с действительным dossier ID; пунктирные кандидаты не притворяются доказанными; карта работает без Risk Web.
