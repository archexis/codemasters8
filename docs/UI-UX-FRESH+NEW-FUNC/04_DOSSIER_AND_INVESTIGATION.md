# 04 — Complex Dossier & Investigation Mode

**Роль:** единое место анализа конкретного ЖК/очереди. Investigation Mode включает функции ведения дела в той же странице, без нового глобального раздела и без пятой вкладки.

## 1. Обязательная компоновка досье

Desktop: слева 1/3 постоянной визуальной области, справа 2/3 контента. Шапка: breadcrumb, ЖК, переключатель очереди, короткий документальный статус, скоринг и дата последней проверки, `Начать расследование` либо `Продолжить #CASE`. В правой области четыре вкладки:

| Вкладка | Единственный основной вопрос | Что в ней есть |
|---|---|---|
| Обзор | Что известно о ЖК? | общее, стадия, БИН/застройщик, законное основание и степень проверки, индикаторы, summary публикаций, риск, входы к доказательствам |
| Проверка | Какие факты подтверждены? | исходники, R1–R6, PDF/скриншот рядом с extracted data, действия проверки отдельных утверждений |
| Связи | Какие подтверждённые/возможные отношения? | Risk Web граф/список, выбор узла/ребра, доказательства связей |
| Хронология | Что и когда изменилось? | события, readiness over time, официальные отчёты, drone-снимки, date compare, аналитическое резюме |

Слева `Спутник | 3D-модель* | Фото` (`*` только при наличии). На вкладке «Хронология» выбор даты синхронизирует визуальный материал слева; если исторического спутника нет — показывать статичную подложку с явной датой/неизвестной датой, не симулировать снимки прошлых лет. На вкладке «Связи» кнопка `Развернуть граф` временно скрывает левую колонку без потери выбора. На мобильном визуальная область становится сворачиваемым верхним блоком.

## 2. Режим чтения ≠ Investigation Mode

**Чтение:** смотреть любые материалы, риск и историю, переходить по источникам; проверка фактов и итоговое решение недоступны. Нажатие «Подтвердить факт» в режиме чтения сначала предлагает открыть/создать дело. Ручная оценка AI-гипотезы во вкладке «Публикации» — только триаж и не заменяет эту проверку.

**Investigation Mode:** нажать `Начать расследование` → создать `Case(caseId, complexId, phaseId, owner, status)`; перенаправить на `/cases/:caseId` с тем же `ComplexDossierLayout`. Панель дела компактна, по запросу раскрывается как drawer в пределах правой части; **не добавлять третью постоянную колонку**, иначе 1/3+2/3 перестанет работать.

Постоянная узкая плашка режима: `CASE-...`, ответственный, статус, дата последнего действия, `Материалы (n)`, `Предпросмотр сигнала`. Из вкладок доступны только релевантные действия `Добавить в дело` и `Открыть источник`. Нет отдельного гигантского «центра ИИ».

## 3. Workflow дела

```text
create case (draft)
  └─► collect artifacts (source untouched)
          └─► examine claims / confirm or reject FACTS (each with actor + date)
                   └─► deterministic score recalculation
                            └─► review signal preview
                                     ├─► Confirm signal (confirmed)
                                     └─► Return for revision (returned)
```

`Подтвердить факт` (например, цитату/документ) ≠ `Подтвердить сигнал` (итоговое решение). Это раздельные команды с разными правами и журналами. Контент не может «самоподтвердиться» из LLM. Подтверждение сигнала требует валидации комплекта **тех факторов, которые включены в сигнал**, а не обязательно R1+R2 для любых зон. Подтверждённый сигнал не отправляет ничего в МИО.

Предусмотреть возвращение дела к доработке, продолжение и создание новой версии сигнального snapshot при изменении доказательств. Не редактировать задним числом уже зафиксированный PDF/решение: добавить версию и audit event.

## 4. Панель «Материалы дела»

Фильтры: `Все | Не проверено | Подтверждено | Отклонено` и тип `Публикации / Документы / Связи / События`. Каждая строка содержит тип, источник, время фиксации, ссылку на оригинал, текущий статус, автора подтверждения. «Добавить в дело» сохраняет ссылку на существующий Evidence, не копирует содержимое и не означает автоматическое подтверждение.

## 5. Выход и навигация

- Из карты, публикаций и реестров пользователь попадает в **один и тот же** `complexId/phaseId`.
- Для текущего объекта показывать `Продолжить расследование`; с несколькими делами — селектор конкретного дела.
- `Назад` сохраняет контекст источника перехода (фильтры публикаций или положение карты).
- Несохранённые правки требуют подтверждения; сервер является источником истины для статусов и audit trail.
- Смена очереди вне рамок расследования допустима; **в активном деле** переход на другую очередь открывает её досье, но не переносит автоматически старое дело.

## 7. Состояния и ошибки

Case не создан → кнопка «Начать». Case существует → «Продолжить». У пользователя нет права изменять → только просмотр + причина. Ошибка при подтверждении → действие не фиктивно принято; вернуть явную ошибку. Фоновая загрузка PDF/CV не блокирует просмотр досье и сохранение проверок, если они независимы.

## DoD

Одинаковые четыре вкладки в режиме чтения и дела; любой тип источника добавляется в case, далее доступен по ссылке; подтверждение факта не подменяет подтверждение сигнала; решение содержит актор/время; после refresh дело сохранено; PDF доступен из дела по `07`.
