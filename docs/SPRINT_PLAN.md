## Решения, которые не нужно придумывать

- Сохраняем Svelte/TypeScript/Vite, FastAPI, Supabase и JSONB workspace. Новые framework, нормализация в десятки таблиц и визуальный редизайн вне scope.
- Окружение приёмки MVP: локальный подключённый Supabase + FastAPI + настоящий внешний AI. DEMO проверяется отдельно. Production deployment и отправка заявки не подразумеваются.
- R1–R6, веса и зоны — из §5 ТЗ. R5 использует абсолютную разницу: ТЗ говорит о несовпадении, а не только завышении. Для R6 не выдумывать числовой порог значимой просрочки.
- S1 вводит минимальные структурированные доказательства; S2 обеспечивает надёжное хранение. S1 не зависит от будущего S2.
- S2 вводит типы AI run и signal snapshot; их полноценные потоки и UI — в S4/S5. Это заранее согласованный контракт.
- Неизвестное хранится как неизвестное. Не подставлять сегодняшнюю дату публикации и не выдумывать источник для прохождения теста.
- Работающую функцию сохраняем, если она проходит новые тесты. Старые тесты не доказывают отсутствие обходов.
