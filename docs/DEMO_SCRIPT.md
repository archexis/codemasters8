# Демонстрация текущего пути SAQ QURYLYS

Данные примера синтетические. Риск не устанавливает факт правонарушения.

1. Открыть `#/map`: A/B/C имеют 35/70/10. Поиск «Сарыарқа», фильтр красной зоны, список → досье. Объяснить, что новое дело начинает собственную проверку с нуля.
2. `#/publications?add=1&complex=SQ-003`: текст «Платная бронь квартиры 987 650 тенге до сдачи дома», площадка «Учебный источник», реальная указанная дата материала. Неизвестную дату оставить пустой.
3. DEMO: локальный parser. Connected: внешний AI только с согласованным бюджетом. Показать точную цитату и модель. Принять гипотезу R2 с обоснованием. Проверить, что это ещё не факт и балл не увеличен.
4. Досье → Проверка → Начать расследование. Новый score 0: это отсутствие проверенных фактов дела, а не заключение о безопасности. Подтвердить факт R2 после сверки оригинала, источника и даты. Score 25/yellow.
5. Предпросмотр сигнала → обоснование → Подтвердить сигнал. Показать версию 1, автора/время, материал, цитату и ограничения. Печать / сохранить PDF; connected также имеет серверный PDF.
6. Открыть пересмотр с причиной → К досье → отклонить факт с новым обоснованием. Текущий score 0. Вернуть сигнал на проверку; после reload выбрать версию 1: прежние 25 и цитата сохранены.
7. Связи: общий аккаунт — кандидат, а не общий владелец. Добавить источники, проверить связь отдельно; score не меняется. Хронология различает дату события и дату фиксации.
8. В меню аналитика → Резервная копия: скачать ZIP JSON+файлы+SHA256. Для восстановления использовать отдельное пустое workspace; импортированные факты требуют новой проверки.

При недоступном provider сохранить материал без AI. Не выдавать архивный результат за новый inference. Поддерживаемый DEMO сценарий — tests/e2e/ux-target.spec.ts и workflows.spec.ts; connected — tests/live/investigation.spec.ts. Runtime PDF/screenshots/traces сохраняются в test-results; копировать отобранные файлы в docs/acceptance только после остановки Vite.

Актуальные результаты и ограничения: [REPORT](acceptance/score-maxxing/REPORT.md). Архивные записи S5/S6 доступны в прежних каталогах и помечаются REPLAY.
