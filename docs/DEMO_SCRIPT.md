# Демонстрация SAQ QURYLYS

Пользователь — аналитик, сопоставляющий публикации, материалы проверки и решения. Продукт сохраняет объяснимую версию сигнала; риск не является юридическим вердиктом. Измерений экономии времени не заявляем.

1. Открыть обзор и карточку. Маркировать synthetic кейс, показать unknown и происхождение материала.
2. Новый текст: «Продаём квартиры в строящемся ЖК Синтетический S5. Дом ещё не введён в эксплуатацию, сдача в 2028 году. Депозит 654 000 тенге обязателен для бронирования квартиры.» Указать synthetic URL/date.
3. В connected режиме выполнить реальный AI. Показать model, runId, prompt version и точные цитаты R2/R3. При provider failure показать ошибку; резервные материалы не выдавать за live inference.
4. Человек подтверждает R2 с обоснованием; R3 — только после отдельного датированного synthetic акта неввода. R1 — после synthetic сверки обоих допустимых оснований. Score 70/red объясняется 35+25+10.
5. Подтвердить сигнал v1, reload, открыть PDF. Изменить факт: отозвать R2 → текущий draft 45/yellow. Открыть v1: прежние 70/red и материалы неизменны. Вернуть новую версию с причиной.
6. Показать полный backup отдельно от JSON export, ограничения OCR/скрейпинга/живых госреестров.

Резервный **реально выполненный synthetic connected** кейс S5-f1827716: [run и обе версии](acceptance/s5/connected.json), [PDF v1](acceptance/s5/pdf/connected.pdf), [страница 1](acceptance/s5/pdf/connected-1.png), [страница 2](acceptance/s5/pdf/connected-2.png). Это архив выполненного inference, не новый live запрос. Последовательные S6 backup screens этого же case находятся в acceptance/s6/demo/. Локальное воспроизведение исторических snapshot маркируется REPLAY.

Svelte, Supabase, FastAPI, MapLibre, Zod и остальные библиотеки перечислены lockfiles; LLM DeepSeek Flash через OpenAI-compatible API. AI-assisted разработка и тесты не заменяют человеческие решения/юридическую проверку. Production и отправка заявки отдельно не выполнялись.
