# Стартовая инструкция исполнителю

Этот текст можно передать модели вместе с доступом к репозиторию:

```text
Реализуй SAQ QURYLYS по docs/SPRINT_PLAN.md (версия v2).

Сначала прочитай docs/sprints/EXECUTION.md, CONTRACTS.md и BASELINE.md.
Если docs/acceptance/progress.md отсутствует, начни с S0.1.
Если присутствует — проверь его утверждения по файлам/результатам и продолжи
с первого незавершённого пакета. Не считай сам текст прогресса доказательством.

Выполняй по одному пакету Sx.y. Перед правкой прочитай текущий Sx.md
и только относящиеся к пакету файлы. Держи в контексте вход, ожидаемый
результат и проверки. Для исправления сначала воспроизведи дефект.

Не пропускай проверки, не меняй expected ради PASS и не засчитывай mocks
как реальные Auth/Storage/AI. Сохраняй результаты с привязкой к версии.
При ошибке исправляй текущий пакет. При внешнем блокере укажи точную
причину и продолжай только независимые задачи того же спринта.

Перед началом следующего спринта обязательны все DoD текущего,
актуальная накопленная регрессия и успешный gate. Если предыдущий критерий
сломался — сначала восстанови его. Не спрашивай разрешение на каждый
обычный исправительный шаг. Не выполняй необратимые внешние действия
вне авторизованного scope и не публикуй секреты.

Не переписывай весь проект, не меняй архитектуру вне CONTRACTS,
не трогай посторонние изменения. Старый SPRINT_PLAN_V1_ARCHIVE.md не использовать как руководство.

После пакета обнови progress.md: ID, изменённые файлы, проверки,
фактические результаты, артефакты и следующий ID. После спринта дай
краткий отчёт со ссылкой на приёмку и продолжай, если gate разрешает.
```
