# Исторические планы S0–S6

Планы, контракты и протокол исполнения относятся к прежним этапам. Формулировки «текущий», «следующий» и «ещё не реализовано» внутри читаются в контексте соответствующего этапа.

Точка входа — [актуальная документация](../README.md). Реальную архитектуру описывает [ARCHITECTURE.md](../ARCHITECTURE.md), проверки — [DEVELOPMENT.md](../DEVELOPMENT.md).

Имена файлов сохранены: на них ссылаются приёмка и инструменты. `PLAN_INDEX.json` и `CONTRACTS.md` — исторические основания разработки и тестов, а не полное описание текущего API. Не начинайте повторное исполнение S0–S6 по старому `START_HERE.md`.
