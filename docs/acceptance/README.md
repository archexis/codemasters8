# Исторические доказательства приёмки

Здесь находятся результаты отдельных прогонов S0–S6, UX и score-maxxing: журналы, manifests, PDF и screenshots. Они описывают указанную в каждом отчёте версию и среду, а не текущую рабочую копию.

Для запуска и разработки используйте [актуальные руководства](../README.md). Последний из сохранённых пакетов — [score-maxxing от 19 октября 2026 года](score-maxxing/REPORT.md).

Каталог оставлен по прежнему пути: `tools/`, sprint gate и регрессионные тесты читают отсюда критерии и fixtures. Перемещение без изменения инструментов нарушит воспроизводимость. Исходные JSON, хеши и доказательства при редактуре руководств не переписываются.

Новые прогоны сохраняйте в `test-results/`. Отобранные доказательства добавляйте отдельно с датой, командой и commit либо manifest. Исторический PASS не заменяет свежую проверку или проверку доступности LLM.
