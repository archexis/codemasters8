# Результат переноса — 18.10.2026

Текущая версия использует Svelte 5 runes / TypeScript / Vite, Tailwind 4,
MapLibre GL JS, Supabase JS (PostgreSQL, Auth, Storage, RLS), FastAPI и
Supabase Edge Function с внешним OpenAI-совместимым LLM API.

Исходные JS IIFE и Leaflet удалены. Полностью перенесены 16 объектов,
13 публикаций, 11 реестров, происхождение данных, формула R1–R6 и маршруты.
Сохранены главная/быстрая проверка, список/поиск/фильтры/карта/спутник,
карточка объекта, публикации/связи, примеры A/B/C, CSV-предпросмотр,
ручной анализ/подтверждение/отклонение, наблюдения и файлы, журнал,
сигналы и печать. Добавлены формы создания/редактирования объектов.

## Ключевые исправления

- Браузер больше не хранит ключ LLM и не вызывает провайдера напрямую.
- Реальный вход через Supabase Auth; DEMO подписан и отделён.
- Решения сохраняются атомарными PostgreSQL RPC с серверным reviewer.
- RLS ограничивает данные и Storage UUID пользователя; прямой UPDATE запрещён.
- Конфликт версий не перезаписывает решение другой вкладки.
- Отказ от AI-гипотезы сохраняется вместе с публикацией и журналом.
- Файлы имеют стабильный ID и сохраняются после reload, включая локальное DEMO.
- R1/R2/R5 проверяются перед подтверждением на клиенте и сервере.
- Пересмотр готовности и оснований снимает устаревшие подтверждения.
- Изменение фактов переводит сигнал в черновик, решения хранят снимки.
- Факторы не считаются дважды при повторном коде.
- Определение площадки использует hostname; CSV поддерживает multiline quotes.
- Дедуп использует полный текст; длинные цитаты не заменяются многоточием.
- Отрицание относится к платёжному выражению в своей части предложения:
  «без комиссии» и «не упустите» больше не скрывают депозит.
- Прямые ссылки корректно задают title, неизвестные страницы дают not-found.

## Границы результата

Docker стал доступен в ходе работы. Локальный Supabase поднят, обе миграции
применены, выполнен настоящий сквозной тест Auth/Storage/RPC и FastAPI.
В `.env` записаны только публичные локальные ключи и URL; файл игнорируется Git.
Фронтенд работает на 127.0.0.1:5173, API на 127.0.0.1:8000, локальная почта
на 127.0.0.1:54324.

После предоставления ключа подключён настоящий DeepSeek (`deepseek-flash`).
Шесть прямых проверок через Edge и браузерный сценарий с реальным анализом,
подтверждением и сохранением прошли. Результат: `DEEPSEEK_TEST_REPORT.json`.
Ключ находится только в игнорируемом `.env.edge`.

Облачный Supabase, доставка внешних писем и production-развёртывание ещё
не проверены. Команды подключения облачных сервисов приведены в README.

Схема — персональные versioned JSONB workspaces, а не общие организации с
несколькими ролями. Старое browser-состояние `sq_state_v1` не импортируется
автоматически; исходные данные сохранены в `src/lib/seed.json`.
Нет live-скрейпинга/OCR/CV и автоматической проверки госреестров.
Предыдущие документы аудита описывают версию до этого переноса.
