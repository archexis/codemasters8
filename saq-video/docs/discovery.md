# Проверка продукта перед съёмкой

Изучены package.json, src/App.svelte, src/components/RiskMap.svelte, ComplexDossier.svelte, Relations.svelte, FactCandidate.svelte, CaseSignal.svelte, src/lib/navigation.ts, seed.json и e2e-сценарии подготовки/проверки. Также пройден сценарий через реальный браузер до записи.

- Фреймворк: Svelte 5; сборка и локальный сервер: Vite 7. Запуск `npm run dev -- --port 5174` из корня приложения.
- Карта: MapLibre GL 6, настоящие растровые тайлы OpenStreetMap. Начальная камера 82.617 / 49.917, zoom 12. Поиск и список объектов, карточка предпросмотра, переход к досье. X-Ray не используется.
- DEMO: локальное хранилище отдельного чистого контекста браузера. Нет входа в Supabase, сетевых изменений рабочих данных или изменений инфраструктуры.
- SQ-001: «Янтарный мыс»; ТОО «Янтарь Строй» (вымышленное); координаты 49.889851 / 82.61502. БИН неизвестен. Не придумывались документы и реквизиты.
- Досье: Обзор / Проверка / Связи / Хронология. Фильм показывает обзор, реальные записи связей и проверку; AI-иллюстрации внутри штатного UI сохраняют маркировку «AI-реконструкция» и не считаются доказательством.
- Реестр/документ: существующая «Демо-выписка из учебного реестра» видна в типизированных связях. Отсутствие разрешения не объявлено доказанным.
- Evidence Ledger: оригинальный сохранённый текст, кандидат с точной цитатой, обоснование аналитика, подтверждённый факт. Всё это реально выполнено в локальном DEMO.
- Встроенная подготовка создаёт учебную публикацию №1 с депозитом 175 000 тенге. Нет URL внешнего оригинала. Показано открытие сохранённого материала, внешняя проверка не заявляется.
- Сигнальная карточка содержит проверенный R2 (+25), цитату, материал и обоснование. Дело остаётся черновиком; финальное решение по сигналу не нажималось.
- Бренд приложения реализован текстом и CSS-символом S. Для финала использована разрешённая чистая типографика SAQ QURYLYS; новый логотип не создавался. Шрифт фильма: установленный Segoe UI; лицензия системного шрифта, файл шрифта не распространяется.

Graphify CLI был проверен первым для навигации по существующему графу; graphify-out/graph.json отсутствует. Не создавался новый граф вне разрешённого saq-video/. Продукт изучен по исходникам и действующему интерфейсу.
