UI приложения не изменяется. Только видеомонтаж, кадрирование реальной записи и титры вне области интерфейса. Сцены 1–5 — видео реального браузера, снятые отдельно с размером 2560×1440. Скриншоты используются для контроля, не вместо взаимодействий. Исходные WebM сохраняются в out/raw; нормализованные CFR H.264 в public/footage. X-Ray не открывается и не показывается.

Честное отклонение от пожелания внешнего первоисточника: проверяемый встроенный материал не имеет внешнего URL. Открывается его сохранённый оригинал внутри Evidence Ledger. Справочные внешние ссылки других DEMO-публикаций не выдаются за первоисточник и не используются для подтверждения. Проверяется содержание учебного материала, не реальное нарушение.
